**(c) New ideas, by expected gain per GPU-hour.**
1. Joint input dropout (0 GPU-h, recipe change before S1). Independent 20% / 10% drops give a both-dropped rate of only 2%, so the unconditional branch that `--cfg` and S2's distillation rely on is barely trained. CFG uses 10-20% (Ho & Salimans, arXiv:2207.12598); DMD2 / CausVid / Self-Forcing distil a CFG-guided teacher (arXiv:2405.14867, 2412.07772, 2506.08009). Make it explicit: ~10% both, ~10% guide only, ~10% tokens only.
2. Overlapped windows with fused denoising at rollout (0 training GPU-h, ~1.3x sampling). Windows are sampled independently with different noise and the signed ID / W count the seam every 20 ticks (`restart` only affects the 170-tick drift check). Average the velocity over a 1-latent overlap each step: MultiDiffusion (arXiv:2302.08113), Gen-L-Video (arXiv:2305.18264). Rollout option only; compare on the same checkpoint.
3. Representation alignment as an auxiliary loss (~3% per update + one feature cache): align a mid-block DiT feature with frozen DINOv2 features of the key frames. REPA (arXiv:2410.06940) reports much faster convergence from scratch; VideoREPA (arXiv:2505.23656) applies it to video fine-tuning. Gain on a pretrained LoRA fine-tune is less proven: a matched arm after the main run, not a change to the one long bet.
