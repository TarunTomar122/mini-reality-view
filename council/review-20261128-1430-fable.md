**(c) New ideas, by gain per GPU-hour (all untested here).**
1. **Add the answer key to the self-forcing loss (0 GPU-h).** Text-to-video students have no ground truth for their own rollouts; we have the key at every tick and the guide pins the content. Next to the DMD term, regress the student's own-rollout output on the cached key latents, small weight. DMD v1 used a paired term (arXiv:2311.18828); DMD2 (arXiv:2405.14867) dropped it only because building pairs was costly. It gives a correct gradient from update 1, so teacher ODE pairs may not be needed (~3 s of teacher sampling each, ~7 slice-h for 8k). Risk: blur where the guide has holes; the DMD term is there for that.
2. **Compute camera-token keys / values once per latent, not once per denoising step (0 training).** Tokens are 48% of GPU time; I estimate ~3/4 of that is projecting 4,662 tokens through 30 blocks, which does not depend on the noise level. Reuse over the student's 4 steps removes ~55% of the token cost at inference and in every S2 rollout. (Astra logged this at 09:36; the estimate is new.) **S2 design brief (new files only: `mrv/wan_causal.py`, `scripts/train_wan_student.py`, `scripts/wan_s2_tests.py`, `scripts/wan_s2_timing.py`; frozen files imported, never edited).**
- **Networks.** Student, real score and fake score (critic) all start from the S1 budget-stop checkpoint. Real score frozen. Student and critic train their LoRA + new modules.
- **Block = 1 latent (4 ticks; a drive's first latent = 1 tick).** This is the lag the owner accepted; each extra latent per block adds 0.4 s. Self-attention gets a block-causal mask (training) = KV cache (inference), set through a swapped attention processor. Guide channels and camera tokens are already per-latent. The guide's VAE encode must run as a stream, not one call per segment.
- **Cache.** The last 4 finished latents + the current one (2,560 tokens = the teacher's clip). A finished latent is written to the cache by one extra forward at a small fixed noise level, the same in training. Oldest latent evicted; the time index keeps counting (rotations in fp32). Keep-the-first-latent anchor only if Astra's eviction test shows drift.
- **Stage 2a, <= 5 slice-h (~6,000 updates at the S1 rate):** causal fine-tune on real clips with an independent noise level per latent (Diffusion Forcing, arXiv:2407.01392). Replaces ODE pairs; a causal starting point also avoids the mismatch of copying a bidirectional teacher's trajectories (Causal Forcing, arXiv:2602.02214, ID uncertain). Check first on CPU that the installed diffusers Wan transformer accepts per-token timesteps (added for Wan 2.2 5B); if not, 2a trains through the cache path.
- **Stage 2b, the rest:** 4 steps at sigma 1.0 / 0.857 / 0.667 / 0.4 (shift 2). Own rollout over 5 latents; gradient through one random step per latent, context detached (Self-Forcing, arXiv:2506.08009). Loss = DMD + key term (idea 1). Once stable: 9-13 latent rollouts with a random 5-latent window scored (Self-Forcing++, arXiv:2510.02283).
