**(3) F2, one rule (Astra's, with my hash-on-copy as the mechanism):** a byte is trusted only if it was hashed. After the rebuild one CPU job hashes every cache, token, guide and enc file against its sidecar and writes ONE manifest (path, size, mtime, sha), made read-only, its own sha256 in the gate key and beside DATA_SHA in every run record. Every file a job opens (tokens, latents, Wan weights, the dev panel inputs) is hashed while it is copied to /dev/shm and must equal the manifest. Files a job never opens are covered by the CPU job. Size / mtime is a change alarm only: any mismatch -> refuse to start and re-hash in a CPU job; a match is never used as proof. No sampled hashes.
