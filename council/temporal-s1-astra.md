# Temporal council · Astra · round 1

## 1. Recommendation

Start with the winning TPV checkpoint. Try the existing warm start first. If it holds cars in yesterday’s position or still changes their shape, give the UNet a separate previous-image input. This lets it read an old car’s appearance while rebuilding the current layout from all six cameras. The strongest evidence for training on generated history is local: the earlier DiT’s 20-second L1 rise fell to +1.8 with self_prev. Transfer to SD is an open question. SDEdit motivates the warm start; Self Forcing motivates exposing a model to its own errors. The cache experiment below uses our existing epsilon loss. [SDEdit](https://sde-image-editing.github.io/) · [Self Forcing](https://arxiv.org/abs/2506.08009)

A previous image can preserve only what the chase view encoded. If reappearing cars are still missing, next test pooled DINO tokens from 0.5 and 1 s ago, with age embeddings and rays transformed into the current ego frame using camera-derived motion. Logged poses can give an offline upper bound. Pool before fusion: doubling the 865-token adapter input roughly quadruples its self-attention matrix. Defer BEVFormer until its uncached sequential extractor passes a placement check and its motion inputs can be supplied from cameras. Defer AnimateDiff: its SD 1.5 module fits the backbone, but clip activations cost memory and an online renderer needs causal context. Neither prior demonstrates improved traffic placement here. [BEVFormer](https://github.com/fundamentalvision/BEVFormer) · [AnimateDiff](https://github.com/guoyww/AnimateDiff)

## 2. Measurements

- **Car flicker (primary).** On cropped 512×256 game keys K, estimate bidirectional RAFT flow once. Let W bilinearly sample frame t−1 at the current pixel’s backward-flow endpoint. Keep in-bounds pixels with forward/backward round-trip error ≤1 px, outside the judge’s ego hull in both frames. For prediction P and RGB in [0,255], measure mean absolute channel value of (P_t − W P_{t−1}) − (K_t − W K_{t−1}) on current key-car masks. Pool valid pixels within each drive, then average drives equally. Also report the outer 20% on each side, whole scene, scored drives and valid car-pixel fraction. A disappearing prediction stays in the denominator. Inspect flow overlays on turning cars before trusting the score. [RAFT](https://github.com/princeton-vl/RAFT)
- **20-second drift.** Start from noise, roll without resets for the available ~20 s. Report last-2-s minus first-2-s mean RGB L1 to key (0–255). To isolate accumulated error from scene difficulty, rerender each last-window frame cold with identical cameras and seed. Primary drift penalty D = late mean L1(long rollout) − late mean L1(same model cold). Report actual duration, LPIPS and absolute late L1 too. Only contiguous clips ≥19 s qualify.
- **Placement and memory.** Keep judge_pair.py’s own-car exclusion, ≥8-px car height, Hungarian mask matching at IoU ≥0.3, pooled F1 and mean frame road IoU. Score every fifth tick and separately score first appearances/exits for stale cars. Before seeing predictions, mark events where a car is visible in an earlier rig image, hidden in all six for ≥0.5 s, yet visible in the chase key. Hand-check recall (matched cars / eligible cars) on the last hidden tick, alongside the same tick rendered cold. Count events and drives. With too few events, claim only flicker improvement.

## 3. Paired data

Select 120 official train drives, 6 separate train-split development drives and 24 official validation drives by seeded sampling across traffic density and turning. Keep whole drives and freeze lists before fitting. Render contiguous ~20 s at 10 Hz, about 30k keys total. Extend sim_render.py’s keyframe loop to every replay tick in a fresh keys-only TPV directory. Preserve the judge’s 32-row top crop. Audit tick 5k against existing key k wherever available.

Map each five-tick interval linearly between its actual nuScenes sample timestamps. Per camera choose the nearest in-scene sweep, allow at most 50 ms absolute offset, and record all six tokens, signed offsets and latest capture time (online buffering latency). Break sequences at rejects, repeated rig bundles or scene boundaries. Publish dropped counts and offset percentiles by camera. Cache pooled real tokens and scaled VAE latents by scene/tick, with a unique tick identifier for the judge. Sample contiguous pairs by manifest, never adjacent rows of the flattened trainer. Report anchor-only scores separately: poses between labels are interpolated. Time two full-density drives first. The brief’s sparse-render timing is a lower-confidence estimate for dense keys.

## 4. Experiments and decisions

**Frozen baseline.** Evaluate independent fixed noise and warm strengths 0.5/0.7 on development drives. video_render.py uses 25 steps cold, then 13/17 respectively under its rounding rule. Choose the lowest-flicker strength meeting the placement/drift gates, lock it, and evaluate once on validation. Match seed, cameras, tick rate, CFG 2 and style 2 across methods.

**Three training arms.** From the same winner, use identical target draws, 4,000 updates, effective batch 16, bf16, LR 5e−5, 500-step warmup, rank 64, full-key epsilon loss and 10% camera dropout. DDIM25 at evaluation. At 70 updates/min the gradient work is ~57 min/arm. Cap each at 180 slice-min including startup and rollout generation. Time 100 steps and a cache shard first. Reduce all arms to the same feasible updates if needed.

- **A · Independent continuation.** Train on the dense targets without history. This controls for extra updates and denser supervision.
- **B · Previous key.** Add a trainable zero-initialized 4-channel convolution parallel to frozen conv_in, summing outputs before the next block. Save/load it explicitly alongside LoRA and adapter. Train with previous scaled key latent corrupted as √0.91 z + 0.3 ε; independently zero history on 15% of rows. Infer with equally corrupted previous generated latent, fixed history-noise seed per drive, zero on first tick. Both CFG branches receive the same history.
- **C · Previous generated frame.** Fork B at step 1,000. At steps 1,000 and 2,500 cache detached DDIM25 rollouts on 128 randomly chosen eight-tick train clips, batched across drives. For half the nonzero-history draws use cached predictions paired to their actual successor targets. Preselect these clip/target draws for A/B too. Short, stale rollouts approximate deployment; score long rollouts separately.

Use identical held-out sequences and two paired seeds. Budget rendering, token/latent extraction, validation DDIM sampling and segmentation separately on the rendering/scoring GPUs; cache key masks and flow once. Bootstrap whole drives 2,000 times, keeping seeds together. Adopt warm start if car flicker falls ≥15% versus frozen independent, paired 95% interval excludes zero improvement, upper 95% bound on D ≤+2 L1, and car F1/road IoU point estimates do not fall (lower difference bounds ≥−0.02/−0.01). Apply the same gates to B/C against both A and the best qualifying frozen method. Prefer B if both qualify; choose C over B for ≥1 L1 less drift or ≥10% less flicker with a paired interval excluding zero and placement preserved. Keep A only for a confirmed placement gain over frozen independent with flicker no worse.

## 5. Stop conditions

Review stopped traffic, crossings and turns side by side with keys. Reject gains accompanied by persistent ghost cars, delayed entrances or erased edge traffic. Check ~20 varied key masks by hand and run the VAE round-trip ceiling. If flow rejects most edge-car pixels, the judge misses those cars, or timestamp filtering prevents long rollouts, repair measurement before ranking arms. Wide intervals leave the checkpoint decision open.
