# FACT CHECK — pivot-cond-r1 (Neon / Guard-Verifier)
All cited methods exist; several are misclassified for our camera-only, live-causal, dynamic driving task or carry non-commercial/missing licenses.

## 1. Geometric / Warping / Control (Group 1a)
- **GEN3C** ([2503.03751](https://arxiv.org/abs/2503.03751), [nv-tlabs/GEN3C](https://github.com/nv-tlabs/GEN3C), [HF 7B](https://huggingface.co/nvidia/GEN3C-Cosmos-7B)): Explicit 3D point-cloud cache rendered to target path; Cosmos-Predict1-7B backbone, 121-frame offline chunks (not 10 Hz causal). Code/weights open; **NVIDIA Open Model License** (guardrail-bypass terminates rights).
- **ViewCrafter** ([2409.02048](https://arxiv.org/abs/2409.02048), [Drexubery/ViewCrafter](https://github.com/Drexubery/ViewCrafter)): DUSt3R point cloud + DynamiCrafter (16/25f). Code Apache-2.0, HF weights open, **but static-scenes only** and depends on **DUSt3R (CC BY-NC-SA 4.0)**.
- **ReconX** ([2408.16767](https://arxiv.org/abs/2408.16767), [THU-SI/ReconX](https://github.com/THU-SI/ReconX)): Sparse-view static 3D reconstruction via video diffusion + 3DGS. MIT repo, **static-only**, incomplete/progressive code & weight release.
- **StreetCrafter** ([2412.13188](https://arxiv.org/abs/2412.13188), CVPR'25, [zju3dv/street_crafter](https://github.com/zju3dv/street_crafter)): Vista-based video diffusion conditioned on **LiDAR** point-cloud renders (NOT camera-only depth). Code + GDrive Waymo weights; academic/research terms (Vista/Waymo constraints).
- **FreeVS** ([2410.18079](https://arxiv.org/abs/2410.18079), ICLR'25, [esdolo/FreeVS](https://github.com/esdolo/FreeVS), [HF WOD](https://huggingface.co/Esdolo/FreeVS_WOD)): SVD-based generative NVS on free driving paths using **projected LiDAR** pseudo-images (NOT camera-only). Repo has **no standalone LICENSE file**; weights bound by Waymo Open Dataset non-commercial license.
- **DriveDreamer4D** ([2410.13571](https://arxiv.org/abs/2410.13571), [GigaAI-research/DriveDreamer4D](https://github.com/GigaAI-research/DriveDreamer4D)): **Not** a warped-RGB video conditioner—uses a driving world model (3D boxes/maps) as an offline data machine for PVG/4DGS. Repo releases 4DGS/PVG code & example checkpoints, **not** the proprietary world-model weights.
- **Cosmos-Transfer1 / 2.5** ([NVIDIA/Cosmos](https://github.com/NVIDIA/Cosmos)): Multi-control (depth/seg/edge) ControlNet-style world transfer; Transfer2.5 uses distributed control blocks on Predict2.5-2B (older `cosmos-transfer1`/`2.5` repos archived -> Cosmos 3). Code Apache-2.0; weights **NVIDIA Open Model License**.

## 2. Attention / Multi-View / BEV (Groups 1b–1c)
- **CAT3D** ([2405.10314](https://arxiv.org/abs/2405.10314), NeurIPS'24 Oral): Multi-view diffusion w/ Plücker raymaps; **no official code or weights released** (Google). Static scenes.
- **4DiM** ([2407.07860](https://arxiv.org/abs/2407.07860), Google DeepMind): Cascaded 4D space+time diffusion with metric pose control; **no official standalone code or weights released**.
- **MagicDrive-V2** ([2411.13807](https://arxiv.org/abs/2411.13807), ICCV'25, [flymin/MagicDrive-V2](https://github.com/flymin/MagicDrive-V2), [HF](https://huggingface.co/flymin/MagicDriveDiT-stage3-40k-ft)): MVDiT for 6-cam driving video, **but conditioned on 3D boxes + BEV HD maps + camera/text** (not 6-image-to-novel-view NVS). Repo `LICENSE` placeholder unset; HF weights **GPL-3.0**.
- **SV4D / SV4D 2.0** ([2407.17470](https://arxiv.org/abs/2407.17470), [2503.16396](https://arxiv.org/abs/2503.16396), [HF sv4d2.0](https://huggingface.co/stabilityai/sv4d2.0)): Object-centric monocular video -> orbital multi-view (not multi-cam driving scenes). **Stability AI Community License** (commercial <$1M rev).
- **Stable Virtual Camera / SEVA** ([2503.14489](https://arxiv.org/abs/2503.14489), [repo](https://github.com/Stability-AI/stable-virtual-camera), [HF 1.3B](https://huggingface.co/stabilityai/stable-virtual-camera)): Strongest open Plücker-ray multi-view NVS (1–32 views), **but static-scene assumption** (smears/ghosts dynamic moving cars) and **Non-Commercial License** only.
- **BEVFormer** ([2203.17270](https://arxiv.org/abs/2203.17270), [fundamentalvision/BEVFormer](https://github.com/fundamentalvision/BEVFormer)): Camera-only 6-view spatial/temporal deformable attention to BEV grid; code/weights open, **Apache-2.0**. Perception backbone (no generative video decoder).

## 3. Runtime Camera-Only Depth / 3D Estimators (Q2)
- **VGGT** ([2503.11651](https://arxiv.org/abs/2503.11651), CVPR'25 Best Paper, [facebookresearch/vggt](https://github.com/facebookresearch/vggt), [HF Commercial](https://huggingface.co/facebook/VGGT-1B-Commercial)): 1B feed-forward multi-view depth/pointmaps (<1s on H100). **Up-to-scale only** (needs metric scale alignment from our calibrated rig extrinsics). Baseline NC; `VGGT-1B-Commercial` commercial-ok (gated, no-military).
- **Metric3D v2** ([2404.15506](https://arxiv.org/abs/2404.15506), [YvanYin/Metric3D](https://github.com/YvanYin/Metric3D)): Zero-shot metric monocular depth using known intrinsics (ViT-S/L/g, DINOv2-based). **BSD-2-Clause** code; verify weight commercial terms upstream.
- **Depth Pro / Depth Pro 2** ([2410.02073](https://arxiv.org/abs/2410.02073), [2611.26603](https://arxiv.org/abs/2611.26603), [apple/ml-depth-pro](https://github.com/apple-aiml-research/ml-depth-pro)): Sharp metric mono depth (v1 ~0.3s/img @ 1536px -> 6 views heavy; v2 adds temporal consistency, 24M–872M). **Apple AMLR: non-commercial research only.**
- **UniDepth / UniDepthV2** ([2403.18913](https://arxiv.org/abs/2403.18913), [2502.20110](https://arxiv.org/abs/2502.20110), [lpiccinelli-eth/UniDepth](https://github.com/lpiccinelli-eth/UniDepth)): Metric mono depth, open weights, **CC BY-NC 4.0 (non-commercial only)**.
- **DUSt3R** ([2312.14132](https://arxiv.org/abs/2312.14132), [naver/dust3r](https://github.com/naver/dust3r)): Pairwise static stereo pointmaps; **CC BY-NC-SA 4.0 (non-commercial)**, pairwise optimization too slow for 10 Hz live.

## 4. Doubtful Claims & Guard Flags
- **Sensor & task mismatch:** StreetCrafter & FreeVS rely on **LiDAR** (not camera-only depth); DriveDreamer4D & MagicDrive-V2 use **3D boxes/HD maps** (not 6-RGB-to-chase); ViewCrafter, ReconX, CAT3D, and SEVA assume **static scenes** and fail/ghost on moving traffic. None of the cited generative NVS models run **10 Hz live-causal** out of the box.
- **License / runtime traps:** Depth Pro/v2 (AMLR), UniDepth/V2 (CC BY-NC), DUSt3R (CC BY-NC-SA), SEVA (NC) block commercial weights; CAT3D/4DiM/DriveDreamer4D-WM have no released weights; VGGT is non-metric without rig-baseline Sim(3) scaling, and 6-view mono depth lacks cross-cam scale consistency unless rig-calibrated.
